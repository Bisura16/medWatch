MedWatch API

Flask integration layer wrapping anggota1 sampai anggota5. Deployed on GCP Cloud Run, asia-southeast1.
Frontend: https://medwatch-frontend.vercel.app
Auth: JWT (HS256, 12h expiry) via httpOnly cookie set by Vercel proxy.
Roles: tenaga_kesehatan, masyarakat, admin
